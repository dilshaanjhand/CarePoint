The main idea for my project is to have an easy-to-use, fast, and reliable AI healthcare application for all doctors and patients. 
For doctors, this application assists doctors in finding out what disease a patient has based on the symptoms, and finding treatments based on the detailed disease details. 
For patients, this application enables an easy option to stay healthy via personalized healthcare tips, getting suggestions on treatment based on the illnesses or symptoms they are facing.  
Finally, both doctors and patients have access to the chat agent to get immediate advice. To develop this project, I followed the software development process, starting with brainstorming ideas, researching, designing, implementing, and testing the solution. 
This application is built as a mobile application using the Kivy library and the OpenAI Model, gpt-o4-mini. The application enables users to have personalized and secure accounts by registering as a doctor or a patient. 
When doctors log in, they go to the doctor’s homepage, which has features for disease detection, finding the treatment, and chatting with an expert healthcare agent. 
When patients log in, they have access to personalized healthcare tips (e.g., exercise routine, calorie intake), advice for treatment for a specific illness, and an agent to chat with for any questions they have.
I also prototype how I can provide additional context via pdf file using my deep research on the diseases, symptoms, and treatments, which I developed during the research phase of my project.  
Overall, this project was a great learning experience for me as my first AI application, enabling me to learn about AI models, agents, prompts, context, and cost to develop a good AI application to solve real-world problems. 
As next steps, I plan to extend this application with additional features, for example, having an option to tell the user some food recipes along with calorie guidelines.
